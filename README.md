# 💰 Personal Finance & Spending Behavior Intelligence Dashboard

## 📊 Project Overview

This Power BI project analyzes personal financial behavior to identify spending patterns, savings opportunities, and financial risks.
The dashboard transforms raw transaction data into actionable insights that support smarter financial decisions.

The goal is to demonstrate Business Intelligence capabilities, including data modeling, DAX calculations, behavioral analytics, and data storytelling.

---

## 🎯 Business Objectives

* Analyze income vs expenses trends
* Identify spending behavior patterns
* Detect overspending risks
* Highlight cost optimization opportunities
* Improve savings and financial health awareness

---

## 🧾 Dataset Description

The dataset simulates realistic financial transactions for a one-year period.

### Main Fields:

* **Date** – transaction date
* **Category / Subcategory** – spending classification
* **Amount** – transaction value
* **Type** – Income or Expense
* **Payment Method** – payment type
* **Merchant** – vendor
* **IsRecurring** – recurring payment indicator

---

## 🧱 Data Model

The dashboard uses a **star schema model**:

**Fact Table**

* Transactions

**Dimension Tables**

* Calendar
* Category

This structure enables efficient filtering, time intelligence analysis, and behavioral insights.
